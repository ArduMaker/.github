# 🌐 ArduMaker Cloud

**Infraestructura simple, accesible y pensada para creadores.**

## ¿Qué es ArduMaker Cloud?

En ArduMaker Cloud creamos y alquilamos miniservidores dedicados, configurados especialmente para proyectos de desarrollo web, automatización, educación y emprendimientos digitales.

Nuestro objetivo no es solo ofrecer alojamiento. Queremos que cada uno de nuestros clientes tenga una solución clara, funcional y transparente para desplegar sus ideas sin preocuparse por la infraestructura.

---

## 🚀 ¿Qué ofrecemos?

- ✅ **Miniservidores dedicados** para cada cliente (no compartís recursos).
- 🔐 **Acceso por SSH** hasta 50 usuarios por servidor.
- 🌍 **URLs ilimitadas** para tus aplicaciones, APIs o páginas.
- 🔒 **Certificados SSL gratuitos y automáticos** para todos tus dominios.
- 🛠️ Servidores preconfigurados y listos para desplegar proyectos de forma simple y rápida.

---

## 🧩 ¿Cómo trabajamos?

En ArduMaker no vendemos servidores. Creamos soluciones.

Cada cliente es distinto. Por eso, antes de cualquier entrega, entendemos tu necesidad, diseñamos la solución adecuada y luego la ponemos en marcha. Todo con una comunicación fluida y sin sorpresas.

---

## 🧠 Nuestro stack y conocimientos

Aunque no hablamos mucho de tecnología con nuestros clientes, sí la dominamos. Trabajamos con lenguajes y herramientas modernas como:

- **Python, Django y FastAPI** para backends robustos.
- **Next.js y React** para interfaces rápidas y modernas.
- **Docker, GitHub y NGINX** para automatizar y simplificar despliegues.

Pero lo más importante: **adaptamos todo a lo que vos necesitás**.
